# Leadforge SA — UK Landing Page

Static site: `index.html`, `styles.css`, `logo.png`.

**Before publishing:** replace `https://calendly.com/leadforge-sa/15min` in `index.html` (3 places) with your real Calendly link.

**GitHub Pages:** push to a repo, then Settings > Pages > deploy from the `main` branch, root folder.

**Tip:** If hosting alongside your SA page, put these files in a `/uk` subfolder of your existing repo and access it at `yourdomain.com/uk`.
